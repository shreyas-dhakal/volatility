# Graphify import dialect and provenance

Inspected primary repository [Graphify-Labs/graphify](https://github.com/Graphify-Labs/graphify) at commit `480b61ed91cbc08177dc2c60caa9ffd6c9b95749` on 2026-11-17, by cloning and reading (never executing) upstream source. The source inspected was `graphify/export.py` around lines 405–490: `networkx.readwrite.json_graph.node_link_data(G, edges="links")`, preserved original links, node community labels and canonical `source,target,relation` fields. The extraction schema in `graphify/llm.py` around line 596 uses `nodes`, `edges`, optional `hyperedges`, node `file_type` / `source_file` and edge `relation` / `confidence`.

Supported JSON: object with a `nodes` array and either `links` (export) or `edges` (extraction). Nodes need unique bounded string IDs. Edges need existing string endpoint IDs. Optional `label`, `file_type`, `type`, `source_file` and `file_path` normalize to internal names, with original fields retained under metadata. Edge `relation` normalizes to type, while upstream confidence remains metadata. Directedness is honored. Parallel relationships remain distinct in the exported edge list; traversal uses their adjacency. Hyperedges are preserved as provenance rather than invented pairwise edges.

Limits: 10 MiB JSON, 20,000 nodes, 60,000 edges; default focused view 80 nodes, maximum 200 technical nodes. Search is lexical label/path ranking, not an embedding service. Paths are actual shortest structural paths, not runtime proof. Components, hubs, neighbors and traversal use NetworkX. Candidate boundaries and inferred business links appear as explicitly labelled overlays, separate from imported dependencies.

Upstream EXTRACTED, INFERRED and confidence scores describe the source's claims. Importing them does not verify implementation, business volatility, runtime effects or test coverage. Galvanise never equates churn with business volatility. Scenario reachability is a structural envelope, not a measured regression scope or maintenance saving. Without grounded node mappings evaluation remains qualitative.

`examples/wholesale-graphify.json` is manually authored synthetic data in the supported exporter dialect, with schema provenance included. File paths refer to a fictional application, not a connected repository; they must never be presented as live code citations. The explicit authenticated demo endpoint and CLI seed no connected integrations and make no OpenAI calls.
